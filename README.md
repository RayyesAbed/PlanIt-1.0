# PlanIt

## 🚀 Overview

PlanIt 1.0 is an innovative AI-powered platform designed to empower individuals to become the heroes of their future. By leveraging cutting-edge AI technology, PlanIt aims to significantly enhance the way we approach personal and professional development.

## 🌟 Key Features

- AI-Driven Story Generation
- Smart Task Management
- Interactive Calendar
- Performance Analytics
- Customizable User Profiles

## 🛠 Tech Stack

- **Frontend**: React with Context API for state management
- **Backend**: Express.js
- **Database**: MongoDB
- **Storage**: AWS S3
- **AI Integration**: Google Gemini AI
- **Security**: JWT Authentication
